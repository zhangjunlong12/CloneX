# CloneX

CloneX是一个用于读懂你自己在设备上的操作，并复现操作的个人AI智能助手，AI Agent。

***

致力于改变那些重复性工作的AI Agent交互逻辑。

不需要使用对话的方式描述一件需要agent实现的事情。采取对操作的录制，分析，重放，来实现AI对这件事的完成。

***

CloneX，可以做到对用户操作的录制，在客户端中，记录用户操作，理解操作意图，进行本地记忆存储下来。
并且与openclaw一样有网关监控，可以实现定时调用，重放。
对于各种略有不同，但大同小异的任务，CloneX都可以进行识别存储重放。

例如平时某游戏的每日任务，不会是完全相同的内容，每次点击的地方也会有所不同，CloneX针对用户录制时候的操作，判断过程，结果，最终导向于它对于设备的操作行为，以实现重放。

平时的上下班打卡，这种固定的操作，更是可以有效实现重放。
对于操作不同的行为，可以实现多次录制，录制的越多，重放完成度，准备度也会更高。

***

未来的预想
要进一步拓展，实现连接摄像头等硬件设备，更好对用户行为进行录制，更好记忆用户生活习惯，性格，个性，实现更深程度克隆复制。
重放的话，将会在虚拟现实中进行重放，预演，推算。
